# Sugar

Junction for sugar availability affecting adult mosquito survival.
Dynamic implementations are configured via
[setup_sugar_object](https://dd-harp.github.io/ramp.forcing/reference/setup_sugar_object.md)
and activated by
[dynamic_resources](https://dd-harp.github.io/ramp.forcing/reference/dynamic_resources.md).

## Usage

``` r
Sugar(t, y, xds_obj)
```

## Arguments

- t:

  current simulation time

- y:

  dependent variables vector

- xds_obj:

  an **`xds`** model object

## Value

an **`xds`** object

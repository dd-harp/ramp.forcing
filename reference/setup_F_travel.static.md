# Set up no travel (static)

Setup a static (zero) model for time spent traveling.

## Usage

``` r
# S3 method for class 'static'
setup_F_travel(setup_name, xds_obj, i, options = list())
```

## Arguments

- setup_name:

  a string to dispatch `setup_F_travel`

- xds_obj:

  an **`xds`** model object

- i:

  the host species index

- options:

  setup options for `F_travel`

## Value

an **`xds`** object

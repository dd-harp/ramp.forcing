# Set up visitor availability as a time series function

Setup a time series function for visitor availability.

## Usage

``` r
# S3 method for class 'ts_func'
setup_F_visitors(mod_name, xds_obj, s, options)
```

## Arguments

- mod_name:

  the model name

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

- options:

  a named list to setup `F_visitors`

## Value

an **`xds`** object

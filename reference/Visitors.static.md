# Visitors (static)

For a static visitors model, the function does not update anything.

## Usage

``` r
# S3 method for class 'static'
Visitors(t, y, xds_obj)
```

## Arguments

- t:

  current time

- y:

  the state variable vector

- xds_obj:

  an **`xds`** model object

## Value

an **`xds`** object

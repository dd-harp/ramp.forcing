# Sugar (none)

The default no-op for Sugar. Sugar availability retains its static
default.

## Usage

``` r
# S3 method for class 'none'
Sugar(t, y, xds_obj)
```

## Arguments

- t:

  current simulation time

- y:

  dependent variables vector

- xds_obj:

  an **`xds`** model object

## Value

an **`xds`** object

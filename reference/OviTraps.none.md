# Methods for oviposition traps

Implements
[OviTraps](https://dd-harp.github.io/ramp.forcing/reference/OviTraps.md)
for the none model (do nothing)

## Usage

``` r
# S3 method for class 'none'
OviTraps(t, xds_obj)
```

## Arguments

- t:

  current simulation time

- xds_obj:

  a [list](https://rdrr.io/r/base/list.html)

## Value

[list](https://rdrr.io/r/base/list.html)

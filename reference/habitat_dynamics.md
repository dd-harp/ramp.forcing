# Habitat Dynamics (internal)

Compute and update habitat search weights and bad habitat availability
on the `ML_interface`.

## Usage

``` r
habitat_dynamics(t, y, xds_obj)
```

## Arguments

- t:

  current time

- y:

  state variables

- xds_obj:

  an **`xds`** model object

## Value

an **`xds`** object

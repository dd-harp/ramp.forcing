# Set up the travel model

Setup a model for time spent traveling and exposure while traveling.

## Usage

``` r
setup_F_travel(setup_name, xds_obj, i, options = list())
```

## Arguments

- setup_name:

  a string to dispatch `setup_F_travel`

- xds_obj:

  an **`xds`** model object

- i:

  the host species index

- options:

  setup options for `F_travel`

## Value

an **`xds`** object

# Traps (none)

The default no-op for Traps. Trap availability (`Qtraps`, `Btraps`)
retains its static zero-initialized default.

## Usage

``` r
# S3 method for class 'none'
Traps(t, y, xds_obj)
```

## Arguments

- t:

  current simulation time

- y:

  state variables

- xds_obj:

  an **`xds`** model object

## Value

an **`xds`** object

# Travel Dynamics

Computes and updates `time_at_home` and `travel_EIR` on the
`XY_interface` and `terms`, respectively.

## Usage

``` r
travel_dynamics(t, y, xds_obj)
```

## Arguments

- t:

  current time

- y:

  the state variable vector

- xds_obj:

  an **`xds`** model object

## Value

an **`xds`** object

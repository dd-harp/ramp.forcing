# Methods for exogenous variables describing weather

Implements exogenous forcing by
[Weather](https://dd-harp.github.io/ramp.forcing/reference/Weather.md)

## Usage

``` r
# S3 method for class 'dynamic'
Weather(t, xds_obj)
```

## Arguments

- t:

  current simulation time

- xds_obj:

  a [list](https://rdrr.io/r/base/list.html)

## Value

an **`xds`** object

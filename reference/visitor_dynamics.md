# Visitor Dynamics

Computes and updates `visitors` (availability) and `vis_kappa`
(infectiousness) on the `XY_interface`.

## Usage

``` r
visitor_dynamics(t, y, xds_obj)
```

## Arguments

- t:

  current time

- y:

  the state variable vector

- xds_obj:

  an **`xds`** model object

## Value

an **`xds`** object

# Get Variables

get_variables for `splineX`

## Usage

``` r
# S3 method for class 'splineX'
get_variables(opts, t, y, xds_obj, ix)
```

## Arguments

- opts:

  an options list and dispatching

- t:

  current simulation time

- y:

  state vector

- xds_obj:

  an **`xds`** model object

- ix:

  the species index

## Value

a list of named variables

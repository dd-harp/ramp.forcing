# HabitatDynamics (none)

The default no-op for HabitatDynamics. Habitat search weights and bad
habitat availability retain their static defaults.

## Usage

``` r
# S3 method for class 'none'
HabitatDynamics(t, y, xds_obj)
```

## Arguments

- t:

  current simulation time

- y:

  state variables

- xds_obj:

  an **`xds`** model object

## Value

an **`xds`** object

# Habitat Dynamics

Junction that modifies search weights for habitats and availability of
bad habitat. Activated by
[dynamic_resources](https://dd-harp.github.io/ramp.forcing/reference/dynamic_resources.md).

## Usage

``` r
HabitatDynamics(t, y, xds_obj)
```

## Arguments

- t:

  current simulation time

- y:

  state variables

- xds_obj:

  an **`xds`** model object

## Value

an **`xds`** object

# The `setup` case for exogenous forcing

Call all the functions to set the values of exogenous variables and then
revert the `none` case

## Usage

``` r
# S3 method for class 'setup'
Forcing(t, xds_obj)
```

## Arguments

- t:

  current simulation time

- xds_obj:

  an **`xds`** object

## Value

an **`xds`** object

# Setup the sugar junction object

Initializes `resources_obj$sugar_obj` with class `none`, ready for
dynamic sugar configuration. Called by
[dynamic_resources](https://dd-harp.github.io/ramp.forcing/reference/dynamic_resources.md).

## Usage

``` r
setup_sugar_object(xds_obj)
```

## Arguments

- xds_obj:

  an **`xds`** model object

## Value

an **`xds`** object

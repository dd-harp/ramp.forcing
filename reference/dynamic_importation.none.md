# Activate Dynamic Importation (none)

Upgrades the `importation_obj` from class `none` to class `dynamic` and
initialises the travel and visitor sub-objects.

## Usage

``` r
# S3 method for class 'none'
dynamic_importation(xds_obj)
```

## Arguments

- xds_obj:

  an **`xds`** model object

## Value

an **`xds`** object

# Visitors

Dispatches on `class(xds_obj$XY_interface$visitor_obj)` to update
visitor availability and visitor infectiousness.

## Usage

``` r
Visitors(t, y, xds_obj)
```

## Arguments

- t:

  current time

- y:

  the state variable vector

- xds_obj:

  an **`xds`** model object

## Value

an **`xds`** object

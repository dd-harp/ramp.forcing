# Set up dynamic forcing

If dynamic forcing has not already been set up, then turn on dynamic
forcing and set all the

## Usage

``` r
setup_shock_func(xds_obj, opts = list(), eventT = 365, F_shock = NULL)
```

## Arguments

- xds_obj:

  an **`xds`** object

- opts:

  a list of options to override defaults

- eventT:

  the time when a shock occurs

- F_shock:

  the effects of the shock

## Value

an **`xds`** object

# Set up the visitors model

Setup a model for visitor availability.

## Usage

``` r
setup_F_visitors(mod_name, xds_obj, s, options)
```

## Arguments

- mod_name:

  the model name

- xds_obj:

  an **`xds`** model object

- s:

  the vector species index

- options:

  a named list to setup `F_visitors`

## Value

an **`xds`** object
